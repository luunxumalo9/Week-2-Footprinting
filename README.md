# Week 2-Footprinting and Reconnaissance

Cybersecurity Internship project (Networkwalks). Passive recon against networkwalks.com using Kali Linux tools, performed under written authorization (LETTER OF AUTHORIZATION ON FILE).

Tools used:
* whois - Looked up domain registration and ownership details
* whatweb - fingerprinted the web technologies and CMS in use
* nslookup - resolved the domain to its IP address
* curl -I - pulled up the HTTP response headers
* wafw00f - checked for a Web Application Firewall
* dnsrecon - enumerates DNS records (name servers, mail servers, etc.)
